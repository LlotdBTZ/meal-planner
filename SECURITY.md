# Security policy

Meal Planner is a personal, self-hosted app meant to run on a home network.
Only the latest release is supported.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/LlotdBTZ/meal-planner/security/advisories/new)
with steps to reproduce and the impact you see. Expect a reply within a week.

## Scope notes

- The app is designed for a trusted LAN behind one shared password; it isn't
  meant to be exposed directly to the internet.
- Never include real API keys, cookies, or `.env` contents in a report.
